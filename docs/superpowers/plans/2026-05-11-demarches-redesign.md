# Démarches — Redesign & auto-création — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rendre les démarches actionnables — auto-création à la création d'un statut, changement de statut inline, badges date color-codés, et nettoyage du dialog templates devenu inutile.

**Architecture:** Trois fichiers de composants modifiés (`StatutEditPage`, `StatutsPage`, `ProceduresPage`) + ajout de `sonner` pour les toasts. Toute la logique reste dans les composants existants, aucun nouveau fichier de service. La logique de complétion récurrente est extraite en fonction locale partagée dans `ProceduresPage`.

**Tech Stack:** Next.js App Router, React, Supabase (via `useAdminData`), sonner (toast), DropdownMenu Radix UI (déjà installé via `@radix-ui/react-dropdown-menu`)

```tsx
/**
 * Marque une démarche comme terminée via le dropdown inline.
 * Si elle est récurrente et a une dateLimite, crée l'occurrence suivante.
 */
const completeProcedure = (p: AdminProcedure) => {
  const recurrence = ((p as { recurrence?: ProcedureRecurrence }).recurrence ?? "none") as ProcedureRecurrence;
  const dateLimite = (p as { dateLimite?: string }).dateLimite;

  setProcedures((prev) => {
    const updated = prev.map((item) =>
      item.id === p.id ? { ...item, status: "termine" as const } : item
    );
    if (recurrence === "none" || !dateLimite) return updated;
    const nextDate = computeNextDueDate(dateLimite, recurrence);
    if (!nextDate) return updated;
    return [
      ...updated,
      {
        id: crypto.randomUUID(),
        label: p.label,
        status: "a_faire" as const,
        statutJuridiqueId: (p as { statutJuridiqueId?: string }).statutJuridiqueId,
        organisme: (p as { organisme?: string }).organisme,
        dateLimite: nextDate,
        notes: (p as { notes?: string }).notes,
        recurrence,
        templateKey: (p as { templateKey?: string }).templateKey,
        isAutoGenerated: true,
      },
    ];
  });
};
```

### 5d — Helpers date pour le badge

- [ ] **Ajouter les helpers de calcul de deadline juste avant `TabButton`**

```tsx
const getDeadlineInfo = (rawDate: string | undefined, workflow: string) => {
  if (!rawDate || workflow === "termine") return null;
  const d = new Date(`${rawDate}T12:00:00`);
  if (Number.isNaN(d.getTime())) return null;
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  const in7 = new Date(today);
  in7.setDate(today.getDate() + 7);
  const label = new Intl.DateTimeFormat("fr-FR", {
    day: "2-digit",
    month: "short",
  }).format(d);
  if (d < today)
    return {
      label,
      className:
        "border-red-500/35 bg-red-500/15 text-red-300",
    };
  if (d <= in7)
    return {
      label,
      className:
        "border-amber-500/35 bg-amber-500/15 text-amber-300",
    };
  return {
    label,
    className:
      "border-emerald-500/35 bg-emerald-500/15 text-emerald-300",
  };
};
```
